## Project Description
This device monitoring system program displays the recorded temperature readings. It has a main menu with options to view readings, add readings, classify readings, generate a summary, and exit the program. The classification feature identifies temperature readings as Normal, Warning, or Critical. Lastly, the summary can be generated by selecting Option 4, which displays an overview of the recorded temperature data.
 
## Features
- View all stored temperature readings
- Add a new reading (whole numbers from 0 to 100 only)
- Classify every reading
- Generate a numerical summary and overall status
- Reject invalid menu choices and invalid readings
 
## Requirements
- Python 3 (no external packages)
 
## How to Run
1. Open a terminal inside the Week17 folder.
2. Type: python device_monitor.py
   (On macOS or Linux, type: python3 device_monitor.py)
